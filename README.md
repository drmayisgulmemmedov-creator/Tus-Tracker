# TUS Təkrar və Test İzləyicisi (Tıpta Uzmanlık Sınavı)

Bu proqram **TUS (Türkiyə Uzmanlıq Sınavı)** hazırlığı dövründə oxuduğunuz tibbi branşları, hər branşın alt bölümlərini (mövzularını), atdığınız nəzəri təkrar saylarını və işlədiyiniz **testləri / sual kitablarını** birbaşa səhifə üzərində izləmək üçün xüsusi olaraq hazırlanmışdır.

Proqram **Kompüter (PC/Mac)**, **Planşet (iPad/Android)** və **Mobil telefonlarda (iPhone/Android)** tam uyğun və sinxron işləyir.

---

## 🌟 Əsas Bölmələr və Xüsusiyyətlər

1. **Tamamilə Sizin İdarənizdə:**
   - Heç bir hazır branş və ya bölüm əlavə edilməyib.
   - İstədiyiniz sayda **Ana Başlıq (Branş)** və **Alt Başlıq (Bölüm)** əlavə edə bilərsiniz.
   - Həm branşların, həm də bölümlərin adını istənilən vaxt dəyişə və ya silə bilərsiniz.

2. **🟢 Mövzu Təkrarları (Yaşıl Rəngdə):**
   - Hər bölümün qarşısında yaşıl çərçivəli **`+1 Təkrar`** düyməsi var.
   - Düyməyə vurduqda yan-yana yaşıl rəngli **`✓ 1 Completed`**, **`✓ 2 Completed`**, **`✓ 3 Completed`** şəklində tamamlanma nişanları əlavə olunur.
   - Səhvən klikləsəniz, həmin yaşıl düymənin üzərinə toxunaraq təkrarı silə bilərsiniz.

3. **🔴 İşlənən Testlər və Sual Kitabları (Qırmızı Rəngdə):**
   - Hər bölümün altında qırmızı çərçivəli **`+ Test Əlavə Et`** düyməsi yerləşdirilib.
   - Düyməyə vurduqda testin adını daxil edirsiniz (Məsələn: `tüm-tus soruları 1`, `TTS 2024`, `Vaka Soruları 1` və s.).
   - Əlavə etdikdə dərhal qırmızı rəngdə **`✓ tüm-tus soruları 1 Completed`** kimi nişan yaranır.
   - Qırmızı test düyməsinin üzərinə vurduqda testin adını dəyişə və ya testi silə bilərsiniz.

4. **Ümumi Statistika:**
   - 🩺 **Cəmi Branş**
   - 📑 **Cəmi Bölüm**
   - 🟢 **Mövzu Təkrarları (Cəmi)**
   - 🔴 **İşlənən Testlər (Cəmi)**

5. **100% Daimi Yaddaş:**
   - Bütün məlumatlarınız cihazın öz daimi yaddaşında (`localStorage`) saxlanılır; internet olmasa və ya səhifə bağlansa belə heç bir məlumat silinmir.
   - Kompüterdə server açıq olduqda həm də [`tus_data.json`](file:///c:/Users/Medi%20Club/Downloads/tasks/tus_data.json) faylında saxlanılır.

## 🚀 Proqramı Necə Açmalı?

1. **Kompüterdə:**
   - Qovluqdakı [**`run_tus_tracker.bat`**](file:///c:/Users/Medi%20Club/Downloads/tasks/run_tus_tracker.bat) faylına iki dəfə klikləyin.
   - Brauzeriniz avtomatik olaraq `http://localhost:8080` ünvanında açılacaq.

2. **Telefon və ya Planşetdə:**
   - Kompüterdə proqram açıq ikən **"Cihaz Qoş (QR)"** düyməsinə basın.
   - Ekranda çıxan QR kodu iPhone və ya Android planşetinizin kamerası ilə oxudun.
   - Açılan səhifəni cihazınızın ana ekranına əlavə edin:
     - **iPhone / iPad:** Safari-də *Paylaş* $\rightarrow$ *"Ana Ekrana Əlavə Et"*
     - **Android Planşet:** Chrome-da *3 nöqtə* $\rightarrow$ *"Tətbiqi quraşdır"* və ya *"Ana ekrana əlavə et"*

3. **Cihazlar Arasında Köçürmə (Wi-Fi Olmadan / Hər Yerdə):**
   - İstənilən vaxt yuxarıdakı **"Yedək / Bərpa"** düyməsinə basıb **"Kodu Kopyala"** seçin.
   - Kodu WhatsApp və ya Telegram ilə digər cihazınıza göndərin.
   - Digər cihazda kodu yapışdırıb **"Kodu Tətbiq Et"** vurun — bütün qeydləriniz, təkrarlarınız və testləriniz dərhal köçürüləcək!
